# Quenching Community

**A new view of Azeroth, every time you return.**

Quenching is a graphics and feature enhancement MOD for **Warcraft III**. This organization maintains the client, MOD assets and user guide, and is building a home for community contributions.

[中文首页](README.md) · [Community & downloads](https://qm.txzy.net/)

## Find your way

| Project | Purpose |
| --- | --- |
| [Quenching-Client](https://github.com/QuenchingCommunity/Quenching-Client) | Electron client for settings, resource management, updates and launching |
| [Quenching-Assets](https://github.com/QuenchingCommunity/Quenching-Assets) | Models, textures and other MOD resources |
| [Quenching-Gitbook](https://github.com/QuenchingCommunity/Quenching-Gitbook) | Installation, features and troubleshooting; primarily in Chinese |
| [Quenching-UGC](https://github.com/QuenchingCommunity/Quenching-UGC) | Community work submissions and an index under construction |

## Install

Download the [stable client](https://github.com/QuenchingCommunity/Quenching-Client/releases/latest) and the [MOD resource package](https://github.com/QuenchingCommunity/Quenching-Assets/releases/latest) separately. For a complete resource installation, both full-package A/B ZIPs are required. Follow the release instructions for platform and version compatibility. You need your own legally obtained, working Warcraft III installation.

## Contribute

Report client bugs in Client Issues, asset problems in Assets Issues, and guide corrections in Gitbook Issues. Submit your own work through [UGC](https://github.com/QuenchingCommunity/Quenching-UGC/issues/new/choose), or join the [community](https://qm.txzy.net/).

Include your operating system, client/resource/game versions, graphics mode, reproduction steps and relevant screenshots. Remove personal information from logs. See [CONTRIBUTING](../CONTRIBUTING.md) and [SUPPORT](../SUPPORT.md).
