淬火（Quenching）是面向 **Warcraft III / 魔兽争霸 III** 的画面与功能增强 MOD。我们在这里维护客户端、模型与纹理等 MOD 资源、使用手册，并为社区作者建立作品交流与协作入口。

## 从这里开始

| 你想做什么 | 去哪里 |
| --- | --- |
| 第一次安装，查看公告或选择下载方式 | [淬火社区](https://qm.txzy.net/) |
| 下载 Windows / Mac 客户端 | [Quenching-Client · 稳定发布](https://github.com/QuenchingCommunity/Quenching-Client/releases/latest) |
| 下载完整 MOD 资源或更新包 | [Quenching-Assets · 稳定发布](https://github.com/QuenchingCommunity/Quenching-Assets/releases/latest) |
| 了解安装、功能和常见问题 | [Quenching-Gitbook · 使用手册](https://github.com/QuenchingCommunity/Quenching-Gitbook) |
| 投稿模型、皮肤、地图、战役或教程 | [Quenching-UGC · 创作者入口](https://github.com/QuenchingCommunity/Quenching-UGC) |

**客户端与资源包是两个独立下载。** 客户端负责设置、资源管理与启动；完整包提供模型、纹理等 MOD 资源。首次安装请阅读对应 Release 的说明，完整包 A/B 两个 ZIP 都需要。请使用你合法拥有、能够正常运行的游戏。

## 我们的仓库

- **[Quenching-Client](https://github.com/QuenchingCommunity/Quenching-Client)** — 目前的 Electron 客户端，包含设置、资源切换、更新与启动相关代码。
- **[Quenching-Assets](https://github.com/QuenchingCommunity/Quenching-Assets)** — MOD 资源维护树与发布包。维护分支中的改动不等于已正式发布。
- **[Quenching-Gitbook](https://github.com/QuenchingCommunity/Quenching-Gitbook)** — 安装指南、功能说明和排障文档。
- **[Quenching-UGC](https://github.com/QuenchingCommunity/Quenching-UGC)** — 正在建设的社区作品索引与投稿入口；作品保留作者署名和各自授权。

## 一起完善淬火

欢迎提交可复现的问题、改进文档与翻译，或分享自己的作品。

- 程序问题 → [客户端 Issues](https://github.com/QuenchingCommunity/Quenching-Client/issues)
- 模型、贴图、地形等资源问题 → [资源 Issues](https://github.com/QuenchingCommunity/Quenching-Assets/issues)
- 文档纠错 → [手册 Issues](https://github.com/QuenchingCommunity/Quenching-Gitbook/issues)
- 作品交流 → [淬火社区](https://qm.txzy.net/) / [UGC 投稿](https://github.com/QuenchingCommunity/Quenching-UGC/issues/new/choose)

参与前可阅读[贡献指南](https://github.com/QuenchingCommunity/.github/blob/main/CONTRIBUTING.md)。反馈请附客户端、资源包与游戏版本，操作系统，画质模式，以及复现步骤；分享日志前请移除个人信息。
